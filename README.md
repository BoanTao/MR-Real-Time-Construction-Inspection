# Autonomous Mixed Reality Framework for Real-Time Construction Inspection

This repository provides the dataset, code, and documentation associated with the paper:

> **Autonomous Mixed Reality Framework for Real-Time Construction Inspection**  
> Boan Tao, Jiajun Li, and Frédéric Bosché  
> *Journal of Information Technology in Construction (ITcon)*, Volume 30, pp. 852–874, 2025  
> DOI: https://doi.org/10.36680/j.itcon.2025.035

## Overview

This project presents an **autonomous Mixed Reality framework** for real-time construction inspection and progress monitoring.

The framework integrates **Mixed Reality (MR)**, **Building Information Modelling (BIM)**, **Digital Twin concepts**, and **Artificial Intelligence (AI)** to support automated construction inspection. It aims to improve the efficiency, consistency, and accuracy of inspection processes by connecting on-site visual data with digital design information.

The repository includes source code, dataset information, and examples related to the proposed real-time inspection workflow.

## Key Features

- Mixed Reality-based real-time construction inspection
- BIM-supported object localization and validation
- AI-based object detection from on-site images
- Digital Twin-based inspection workflow
- Construction progress monitoring and quality control
- Real-time visual feedback for inspection results
